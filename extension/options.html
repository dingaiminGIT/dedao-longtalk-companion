得到长谈速览

选择你的模型

API 模式支持 Windows、macOS 和 Linux，不需要本机连接程序。

使用 Chat Completions 兼容接口；正文会发送给此地址对应的服务商。 保存在当前浏览器的本机扩展存储中，重启浏览器、更新或重新加载插件后仍可使用，不通过 Chrome 账号同步。

  1. 安装所选工具并完成其命令行登录。
  2. 在分享包中运行系统对应的安装器：Windows 用 install-windows.cmd；macOS 用 install-macos.command；Linux 用 install-linux.sh。
  3. 回到此页检测程序，再打开得到长谈生成速览。
本机模式需要 Python 3；通过 npm 安装的 CodeBuddy CLI 还需要 Node.js。模型名称可留空，使用工具默认模型。检测只确认程序可用，登录和额度在生成时验证。
长文本与兼容设置长稿会分段整理，再合并为一份速览。模型上下文较小时可调低；分段越多，调用次数越多。详细速览建议 16384；若服务商不支持，可调低。上限不会要求模型用满额度。若兼容服务不支持 response_format，可取消此选项；插件仍会校验输出结构。
API 测试会发送一条很短的测试消息，可能产生少量费用，不发送文章内容。保存设置会停止正在生成的任务。

插件使用你自己的账号与额度。API Key 不会交给得到页面，也不会上传给插件开发者。
