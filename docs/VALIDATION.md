## Ego 浏览器端到端验收

用户手动加载正式 extension 目录后，已完成以下验证：

- 从网页“生成速览”按钮，经扩展后台和 Native Messaging 调用本机 Codex。指定长谈 969 段、约 6.4 万字，72.6 秒返回 5 个重点及 3 项维度评价。
- 生成中收起、展开面板，任务继续运行。
- 发现并修复网页初始标题尚未更新导致缓存未命中的时序问题。重载扩展并刷新文章，立即打开面板，约 1.5 秒读取既有摘要。
- 点击首条“原文”按钮，面板收起，正确定位并高亮对应文字段落。
- 点击重新生成后取消：显示已取消，保留前次结果；观察到对应原生主机及 Codex 子进程均退出。
- 修改偏好后移除旧结果，不自动调用模型；重新打开时按保存的偏好载入已有缓存。
- 实际检查扩展存储：1 条摘要记录，字段为 createdAt、group、result、seconds、version，无正文段落。
- 390 × 844 视口下，面板左右边界为 12 / 378，内容滚动宽度等于可见宽度，没有横向溢出。已恢复桌面视口。

浏览器交互验证使用 Ego。Chrome 的原生主机注册已安装，但未声称在 Chrome 做过同样的自动化验收。

Codex 在线模型运行时间与额度消耗会变动。本机调用不是离线推理。未承诺视频时间轴，不编造时间戳。
